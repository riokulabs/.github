# Getting help

- **Questions and setup help:** GitHub Discussions on this repository, if it is enabled. Search first.
- **Something is broken:** open an issue and fill in the form. The form asks for the details needed to reproduce it.
- **Security problems:** do not use issues. See [SECURITY.md](SECURITY.md).
- **Everything else:** https://@@site@@.

This is maintained by one person in spare time. Replies can take days. A complete report gets answered sooner than a vague one.
