## Commits

- Conventional Commits: `type(scope): summary` (feat, fix, docs, style, refactor, perf, test, build, ci, chore, revert). The changelog is generated from them with git-cliff (`scripts/changelog.sh`).
- Sign off with `git commit -s`. The project is GPL-3.0; outside contributors also sign the Rioku Labs CLA once (`CLA.md` in riokulabs/.github), which the `cla` workflow checks. Never add `actions/checkout` or any step that runs pull request code to `.github/workflows/cla.yml`.
- Optional hooks: `scripts/install-hooks.sh`.

## Never

- Never add AI attribution: no `Co-Authored-By` trailer for an AI tool, no "generated by/with" notes in commits, pull requests, code or docs.
- Never commit decompiled Keen code, game binaries, Keen assets beyond the vanilla reuse this repo documents, or third-party content without a license.
- Never commit secrets or tokens (API tokens, Steam or GitHub credentials, `.env` files).
- Never push, tag or publish (GitHub, Steam Workshop, deploys) unless the maintainer asked for it.
- Never modify the game install or the Steam library directories.
@@extra_never|bullets@@
- Never rewrite published history or force-push shared branches.
