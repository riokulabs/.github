We're a small team making free, open-source game mods and the tools we build them with. We're starting with Space Engineers 2.

## Projects

**Data Center** is a Space Engineers 2 mod with server racks, rack-mount servers, cable trays and the room pieces to put them in. The first release, 0.9.0, is in testing.

**se2-modkit** is our shared toolkit and style guide for making Space Engineers 2 mods on Linux and Windows. It covers the build pipeline, load checks, a Workshop publisher and diagnostics.

Both repositories will open here soon. Until then, you can follow along at [rioku.dev](https://rioku.dev).

## Help build mods

We'd like more people making mods with us, whether that's modelling, scripting, testing in game or writing. Each repository's CONTRIBUTING.md explains how to build and test it. Before your first pull request is merged, you sign our [Contributor Licence Agreement](https://github.com/riokulabs/.github/blob/cla-v1.0/CLA.md) once, by posting a comment on the pull request. Our code is GPL-3.0, and our mods are free and non-commercial.

## Getting in touch

- **Bugs:** open an issue in the repository the problem is in.
- **Questions:** ask in that repository's Discussions.
- **Security problems:** report them privately with a security advisory, not a public issue. See [SECURITY.md](https://github.com/riokulabs/.github/blob/main/SECURITY.md).
- **Everything else:** [rioku.dev](https://rioku.dev)
